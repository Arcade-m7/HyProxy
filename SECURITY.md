# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability or another security-related issue in
HyProxy, please report it privately by email:

<charcaouhaitam1@gmail.com>

Please include enough detail to reproduce the issue, such as the affected
version, a description of the impact, and any relevant proof of concept.

Do not disclose security vulnerabilities publicly until a fix or mitigation
has been released.
